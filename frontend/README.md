# FitFlow Frontend

Flutter/Dart starter area for the FitFlow iOS, Android and authenticated web experience.

Planned HCI flows:
- Home and progress overview
- AI workout planner and explainable plan review
- Workout logging and recovery/undo feedback
- Nutrition search/camera entry with explicit portion controls
- Private challenges and persistent audience/privacy visibility

Native integrations such as HealthKit, Health Connect, camera permissions, secure storage and push notifications should be implemented through reviewed Flutter plugins/platform channels.
